# 🎯 AI-Driven Sentiment Analysis for Social Media Monitoring

### 🧠 Overview
This project aims to analyze public sentiment from **YouTube video comments** using a pre-trained **BERT** model.  
It automatically classifies comments as **Positive**, **Negative**, or **Neutral** and visualizes results through charts and word clouds.

---

### 🚀 Features
- Fetch comments from YouTube videos using the **YouTube API**
- Preprocess text (remove emojis, stop words, punctuation)
- Use **BERT** for sentiment classification
- Visualize results using **Matplotlib** and **WordCloud**
- Interactive **Streamlit** web interface

---

### 🧩 Project Modules
1. **YouTube URL Extraction**
2. **Comment Fetching (YouTube API)**
3. **Text Preprocessing**
4. **Sentiment Classification (BERT)**
5. **Visualization (Matplotlib & WordCloud)**
6. **Streamlit Frontend Integration**

---

### 🛠️ Tech Stack
- Python  
- Streamlit  
- Transformers (Hugging Face BERT)  
- Matplotlib & WordCloud  
- YouTube API
